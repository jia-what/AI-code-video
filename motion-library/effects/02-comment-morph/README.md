# 02 · 评论形变 Comment Morph

![预览](preview.webp)

一条评论，复制成铺满屏幕的评论墙，再倾倒、收缩，重组成一个形象（默认是鲸鱼）。用来表达"很多很多条 X，组成了一个现象"。适合当开头钩子。

[成片 preview.mp4](preview.mp4) · 源码：[`comment-morph.js`](comment-morph.js)、[`index.html`](index.html)

## 看点

| 特征 | 做法 |
|---|---|
| 同一个粒子贯穿始终 | 每个粒子从头到尾都是"同一条评论"：卡片形态（头像 + 两行字）连续变成短线 |
| 由近及远地铺满 | 砖墙按离中心的距离依次出现；相机从 4 倍拉到 0.42 倍（inOutQuint） |
| 倾倒成透视平面 | 整面墙绕 X 轴转约 64°，透视焦距 1500，远处淡出 |
| 收缩成椭圆 | 外圈先动、内圈后动（错峰），卡片在途中压成 9×3.6px 的短线 |
| 重组成剪影 | 剪影按"一行行文字"采样短线，每行间隔 9.5px，短线长短随机；途中带打旋 |
| 辉光 | 短线阶段把整帧模糊 10px 后再用 lighter 叠加一次，便宜又好看 |
| 活着的细节 | 短线随机闪烁；身体做波浪呼吸；眼睛是一颗脉动的亮点；头顶有上升的喷水粒子 |
| 炸开转场 | 每根短线沿离心方向 inExpo 加速飞出，画成拖影，最后白闪到浅色底，可以直接接 01 无限画布 |

## 动作拆解

| 时间 | 动作 |
|---|---|
| 0–0.6s | 主角评论卡，背后有一圈点阵光环；镜头开始后拉 |
| 0.35–1.35s | 评论砖墙由中心向外铺满屏幕（音效：越来越密的 tickroll） |
| 1.25–1.95s | 砖墙向后倾倒；第一行标题逐字浮现 |
| 1.85–2.45s | 收缩成扁椭圆，卡片变短线 |
| 2.35–3.45s | 散开、重组成鲸鱼；第二行标题浮现，重点词渐变 |
| 3.35s | 成形，低音轰鸣；之后闪烁、呼吸、喷水 |
| 4.25s | 光标点击重点词 |
| 5.6–6.35s | 炸开 + 白闪 |

## 用法

```js
import { CommentMorph, WHALE } from './comment-morph.js';

const morph = CommentMorph(ctx, {
  shape: WHALE,                 // 换成任何剪影：{ w, h, body: 'SVG path', fin?: 'SVG path', eye: [x,y], spout: [x,y] }
  center: [960, 660], scale: 1.25,
  zoom: t => ...,               // 砖墙阶段的相机缩放
  T: { wall: [.35, 1.35], tilt: [1.25, 1.95], collapse: [1.85, 2.45], form: [2.35, 3.45], burst: [5.6, 6.3] },
});
render(t) { morph.render(t); }
```

换剪影只需要换一条 SVG 路径（坐标系 `w × h`）。粒子数量由剪影面积和 `sampleDashes` 的 `rowGap` 决定，鲸鱼约 1700 根短线。

## 音效搭配

`tickroll`（铺墙）→ `air`（倾倒）→ `swish`（收缩）→ `sparkle` 加 `shimmer`（成形中）→ `boom`（成形）→ `mouse`（点击）→ `riser` 接 `boom`（炸开）。

## 提示词

```text
做一段 6.5 秒、1920×1080、30fps 的"评论形变"开头：
- 深色底 #06060B，淡点阵。开场是一张白色评论卡（头像、昵称、一行字），背后一圈紫色点阵光环。
- 镜头后拉，评论卡复制成交错排列的砖墙，由中心向外铺满全屏；约 16% 是灰色卡片。
- 砖墙绕 X 轴向后倾倒成透视平面，再错峰收缩成一个扁椭圆，途中每张卡片连续变形成一根 9×3.6px 的圆角短线。
- 短线散开、重组成 <你的剪影，如鲸鱼> 的形状：剪影内部按"一行行文字"排布短线（行距约 9.5px，长短随机），颜色从顶部 #F3F1FF 渐变到底部 #8E7DFF，加整帧模糊叠加的辉光。
- 成形后：短线随机闪烁、身体波浪呼吸、眼睛是一颗脉动的亮点。
- 标题两行逐字模糊浮现，第二行重点词用紫色渐变，光标点击重点词。
- 结尾每根短线沿离心方向加速飞出成拖影，白闪到 #EFEFF3。
- 音效用代码合成并与画面同一时间轴：铺墙用越来越密的嘀嗒，成形用低音轰鸣，炸开用上升音接轰鸣。
```
