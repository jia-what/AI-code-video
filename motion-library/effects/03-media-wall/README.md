# 03 · 封面墙筛选 Media Wall

![预览](preview.webp)

一整面视频封面按对角线波浪浮现，再用顶部标签做筛选：未选中的褪成灰，逐个类别"点亮"回来。用来交代"样本是怎么来的"。最后整面墙缩成光点、散成粒子，可以直接接 04 立体点阵统计。

[成片 preview.mp4](preview.mp4) · 源码：[`media-wall.js`](media-wall.js)、[`index.html`](index.html)

## 看点

| 特征 | 做法 |
|---|---|
| 对角线波浪浮现 | 每张封面延迟 = 列 × 0.035s + 行 × 0.05s，从模糊 10px、缩放 0.86、下沉 10px 浮现 |
| 深色胶囊标签栏 | `#1B1B22` 圆角条；第一个是"全部"，其余是类别加数量；点中后变成紫色胶囊并弹一下 |
| 褪灰 / 点亮 | 未选中：灰度 100%、亮度 1.18、不透明度 0.28；点亮时错峰恢复，并带一点放大回弹 |
| 光标按顺序点 | 光标坐标在页面布局完成后量出来，保证点得准 |
| 缩成光点 | 封面缩小到 7%、变圆、提亮去饱和、加紫色光晕；底色同时从浅灰过渡到深色；最后光点散开成星空 |
| 程序化封面 | `drawCover()` 按类别配色，画人物剪影 / 物件 / 色块，加粗描边大字和时长角标。不用任何真实封面，没有版权问题 |

## 动作拆解

| 时间 | 动作 |
|---|---|
| 0.15–0.6s | 上一段的问题文字逐字模糊消失 |
| 0.5–1.6s | 标签栏下落浮现；封面墙对角线波浪浮现（音效：密集 tickroll） |
| 2.2s | 点"科技 · AI"：其余 40 张错峰褪灰 |
| 2.85 / 3.4 / 3.95 / 4.5s | 依次点亮美食、游戏、搞笑、生活（每次：咔哒 + tick + 一点 sparkle） |
| 5.3–6.4s | 标签栏和光标退场；封面缩成光点，底色变暗 |
| 6.0–7.2s | 光点散开 |

## 用法

```js
import { MediaWall, TabBar, drawCover } from './media-wall.js';

const wall = MediaWall(layer, { cols: 12, rows: 10, cats: { ai: 80, food: 10, game: 10, fun: 10, life: 10 } });
const bar = TabBar(stage, [{ key: 'all', label: '120 个热门视频', first: true }, { key: 'ai', label: '科技 · AI 80' }, ...]);
await document.fonts.ready; wall.paint();         // 字体加载后再画封面

render(t) {
  wall.render(t, { inT: .5, sel: (cat, th) => /* 该类别的点亮进度 0–1，筛选前返回 null */, toDots: seg(t, 5.4, 6.3), scatter: seg(t, 6, 7.2) });
  bar.set('ai', seg(t, 2.2, 2.4));
}
```

想用真实截图时，把 `paint()` 换成往每个 `th.c`（canvas）上画你自己的图片。注意素材授权。

## 音效搭配

`tickroll`（波浪浮现）、`mouse` 加 `tick`（点标签）、`sparkle`（点亮）、`swell` 接 `boom`（变暗转场）、`shimmer`（星空）。

## 提示词

```text
做一段 7 秒、1920×1080、30fps 的"封面墙筛选"动画：
- 浅灰底 #EFEFF3 加点阵和光标聚光。上一段的问题文字先逐字模糊消失。
- 12×10 共 120 张 16:9 视频封面（132×74，圆角 8，间距 12），从左上往右下按对角线波浪依次模糊浮现。
- 顶部深色胶囊标签栏：“120 个热门视频 / 科技 · AI 80 / 美食 10 / 游戏 10 / 搞笑 10 / 生活 10”。
- 光标点“科技 · AI”：该标签变紫色胶囊，其它类别的封面错峰褪成灰白半透明；再依次点其它标签，对应封面逐个点亮并回弹。
- 结尾封面缩成发光的小圆点，底色过渡到深色 #06060B，光点散开成星空。
- 封面用代码生成（按类别配色、人物剪影、粗描边大字、时长角标），不要使用真实封面。
- 音效：浮现用密集嘀嗒，点击用鼠标咔哒加 tick，点亮用闪光，转场用 swell 接 boom。
```
