# 03 · 封面墙筛选 Media Wall

![预览](preview.webp)

一整面封面按对角线波浪浮现，再用顶部标签筛选：选中第一个类别后，其余褪成灰，再逐个类别"点亮"回来。用来交代"样本 / 素材是怎么来的"。最后整面墙缩成光点、散成粒子，可以直接接 04 立体点阵统计。

[成片 preview.mp4](preview.mp4) · 文件：[`config.js`](config.js)（内容）· [`scene.js`](scene.js)（时间轴）· [`media-wall.js`](media-wall.js)（封面墙、标签栏、占位封面）

## 套用

```bash
node harness/render.mjs effects/03-media-wall --config my-configs/03.js --out out/03
```

| 字段 | 说明 |
|---|---|
| `intro` | 开场先模糊消失的一句话（承接上一段）；`null` 跳过 |
| `grid` | `{ cols, rows }`，默认 12 × 10 |
| `all` | 第一个标签的文字（"全部"） |
| `categories` | `[{ key, label, count }]`，`count` 之和要等于 `cols × rows`。第一个类别集中在墙的上方；光标按顺序点击：第一下让其它类别褪灰，之后逐个点亮 |
| `images` | 可选：自己的封面图片地址数组（循环使用，自动裁成 16:9 铺满）；`null` 用占位封面 |

点击时间会根据类别数量自动均匀分布（第一个在 2.2s，最后一个在 4.5s）。

## 看点

| 特征 | 做法 |
|---|---|
| 对角线波浪浮现 | 每张封面延迟 = 列 × 0.035s + 行 × 0.05s，从模糊 10px、缩放 0.86、下沉 10px 浮现 |
| 深色胶囊标签栏 | `#1B1B22` 圆角条；第一个是"全部"，其余是类别加数量；点中后变成紫色胶囊并弹一下 |
| 褪灰 / 点亮 | 未选中：灰度 100%、亮度 1.18、不透明度 0.28；点亮时错峰恢复，并带一点放大回弹 |
| 光标点得准 | 光标坐标在页面布局完成后量出来，换文字、换数量都能对准 |
| 缩成光点 | 封面缩小到 7%、变圆、提亮去饱和、加紫色光晕；底色同时从浅灰过渡到深色；最后光点散开 |
| 占位封面 | `drawCover()` 按类别取色系，画抽象的人物 / 物件 / 几何图形，用白色圆角条代替标题，加时长角标 |

## 动作拆解

| 时间 | 动作 |
|---|---|
| 0.15–0.6s | 开场的一句话逐字模糊消失 |
| 0.5–1.6s | 标签栏下落浮现；封面墙对角线波浪浮现（音效：密集 tickroll） |
| 2.2s | 点第一个类别：其余类别错峰褪灰 |
| 2.85–4.5s | 依次点亮其余类别（每次：咔哒 + tick + 一点 sparkle） |
| 5.3–6.4s | 标签栏和光标退场；封面缩成光点，底色变暗 |
| 6.0–7.2s | 光点散开 |

## 组件

```js
import { MediaWall, TabBar, drawCover, drawImageCover } from './media-wall.js';

const wall = MediaWall(layer, { cols: 12, rows: 10, cats: { a: 80, b: 10, c: 10, d: 10, e: 10 }, images: null });
const bar = TabBar(stage, [{ key: 'all', label: '全部 120', first: true }, { key: 'a', label: '类别 A 80' }, ...]);
await wall.paint();                               // 字体加载后再画封面
wall.render(t, { inT: .5, sel: (cat, th) => /* 0 褪灰 → 1 点亮；筛选前返回 null */, toDots: seg(t, 5.4, 6.3), scatter: seg(t, 6, 7.2) });
bar.set('a', seg(t, 2.2, 2.4));
```

## 音效搭配

`tickroll`（波浪浮现）、`mouse` 加 `tick`（点标签）、`sparkle`（点亮）、`swell` 接 `boom`（变暗转场）、`shimmer`（光点）。

## 提示词

```text

- 结尾封面缩成发光的小圆点，底色过渡到深色 #06060B，光点散开。
- 封面：<你的图片，或者用代码生成的抽象占位封面>。
- 音效：浮现用密集嘀嗒，点击用鼠标咔哒加 tick，点亮用闪光，转场用 swell 接 boom。
```
