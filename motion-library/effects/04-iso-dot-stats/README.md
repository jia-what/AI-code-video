# 04 · 立体点阵统计 Iso Dot Stats

![预览](preview.webp)

把数据做成躺在 3D 地面上的点阵：每一点 = 1 个样本，每块 10×10 = 100 个，命中的点发光，并带一道向上的彗尾。镜头从斜俯视转到低机位正视，再在点阵上方画折线图，大号数字跟着折线一起涨。适合讲"占比"和"趋势"。

[成片 preview.mp4](preview.mp4) · 文件：[`config.js`](config.js)（内容）· [`scene.js`](scene.js)（时间轴）· [`iso-dot-stats.js`](iso-dot-stats.js)（3D 相机、点阵、折线图、背景）

> 默认内容是**示例数据**，画面上也写明了。套用时换成你自己核实过的数据。

## 套用

```bash
node harness/render.mjs effects/04-iso-dot-stats --config my-configs/04.js --out out/04
```

| 字段 | 说明 |
|---|---|
| `legend` | 顶部图例；`<hl>…</hl>` 前会自动加一个发光圆点 |
| `data` | `[{ label, value }]`，每组一块点阵；`value` = 每 100 个里命中几个（发光点数取整），同时是折线数值。建议 5–8 组 |
| `unit` / `decimals` | 数值单位和小数位，如 `'%'`、`1` |
| `intro` | 斜俯视阶段：`counter` 大数字、`note` 胶囊说明（光标停在第一组时显示） |
| `caption` | 正视阶段大号数字下面的说明 |

点阵间距、点亮节奏、折线节点时间都会根据组数自动调整；折线高度按最大值自动缩放。

## 看点

| 特征 | 做法 |
|---|---|
| 真透视 | 自写的小相机 `project(cam, x, y, z)`，参数有偏航、俯仰、距离、焦距；两组相机参数之间插值就能运镜 |
| 粒子归位 | 每个点从屏幕随机位置（可以接 03 散开的光点）错峰飞到点阵上 |
| 发光点加彗尾 | 预渲染的柔光精灵配合 lighter 叠加；向上的渐变短线做彗尾，随噪声闪烁；点亮瞬间放大 1.8 倍再回落 |
| 镜头转换 | 斜俯视（偏航 −0.6、俯仰 −0.95，左上远、右下近）→ 低机位正视（偏航 0、俯仰 −0.52），inOutCubic，约 1.1 秒 |
| 折线图 | 三层描边（14px 淡紫、7px 中紫、3.2px 亮线）做出发光感；线下渐变面积；每个点有虚线连到对应点阵块 |
| 数值跟随 | 大号渐变数字随折线头部插值增长；光标跟着折线头走 |
| 太空背景 | 深色底、左侧紫色氛围光、淡点阵，加 90 根斜向流光线 |

## 动作拆解

| 时间 | 动作 |
|---|---|
| 0.1–1.5s | 散落的点错峰飞回，组成点阵块；图例浮现 |
| 1.7–3.7s | 各块的发光点依次点亮（每块一声 sparkle）；计数器和说明胶囊出现 |
| 3.9–5.0s | 镜头从斜俯视转到低机位正视 |
| 5.0–8.2s | 折线从左到右画出，数值标签逐个弹出，大号数字同步增长（tick 加 tickroll） |
| 8.15s | 到达终点，低音轰鸣加闪光 |

## 组件

```js
import { DotBlocks, drawLineChart, drawSpace, lerpCam, project } from './iso-dot-stats.js';

const blocks = DotBlocks(ctx, data, { spacing: 200 });
const camA = { tx: 0, ty: 0, tz: 0, dist: 1600, yaw: -.62, pitch: -.95, f: 1500, sx: 1000, sy: 560 };
const camB = { ...camA, yaw: 0, pitch: -.52, sx: 960, sy: 870 };
const cam = lerpCam(camA, camB, seg(t, 3.9, 5, ease.inOutCubic));
drawSpace(ctx, t);
blocks.render(t, cam, { gather: seg(t, .1, 1.5), ignite: k => seg(t, 1.7 + k * .3, 2 + k * .3) });
drawLineChart(ctx, points, head, { base, drops });   // points 用 blocks.anchor(cam, k) 计算
```

## 音效搭配

`shimmer` 加 `tickroll`（粒子归位）、`sparkle`（每块点亮，音高递升）、`air`（运镜）、`tick`（折线每到一个点）、`tickroll`（数字增长）、`boom`（到达终点）。
